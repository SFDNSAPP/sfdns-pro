# DNS Changer & DoH Proxy for Android

هذه نسخة عربية من ملف README. المحتوى الفني والهيكل مطابقان تمامًا للإصدار الإنجليزي؛ تم تغيير اللغة فقط.

---
## 🌟 الميزات الرئيسية

- 🛡️ خصوصية أولاً ودعم DoH (DNS-over-HTTPS) مشفر.
- ⚡ توجيه VPN محلي خفيف الوزن: يتم التقاط طلبات DNS فقط (المنفذ 53 UDP/TCP).
- 🚀 قائمة مبدئية من عُقد DNS السريعة والموثوقة: Cloudflare، Google، Quad9، Shecan، إلخ.
- 🧩 عناصر واجهة (Widgets) وQuick Tile للوصول السريع.
- 🎨 واجهة مستخدم عصرية (Glassmorphic)، وضع داكن، ومؤشرات حالة DNS.
- 🔄 الاتصال التلقائي عند الإقلاع (اختياري).

## 📥 التحميل

قم بتنزيل أحدث ملف APK موقع من صفحة [Releases](https://github.com/SFDNSAPP/sfdns-pro/releases).

---
## 🏗️ البنية وطريقة العمل

1. ينشئ التطبيق واجهة TUN افتراضية محلية (`VpnService`) ويعترض وجهات DNS فقط.
2. عند تفعيل DoH، تُحوّل استعلامات DNS المُعترضَة إلى طلبات HTTPS متوافقة مع RFC 8484 وتُرسَل عبر TLS إلى المحلّل (resolver).
3. يتجنّب التطبيق التخزين الدائم للوائح (logs) ولا يرسل بيانات تتبّع إلى طرف ثالث.

## 🚀 بدء سريع

1. ثبّت ملف APK من صفحة [Releases](https://github.com/SFDNSAPP/sfdns-pro/releases).
2. افتح التطبيق وامنحه إذن VPN.
3. اختر محلّل (resolver) من القائمة أو أدخل عناوين DNS مخصصة.
4. فعّل DoH في الإعدادات إن رغبت.
5. استخدم Quick Tile أو الودجات للاتصال بسرعة.

---
## 🔒 الأمان والخصوصية

- `allowBackup` معطَّل.
- تم تعطيل حركة المرور النصّية غير المشفّرة (`usesCleartextTraffic="false"`).
- لا يتمّ تسجيل استعلامات DNS أو إرسال telemetry إلى طرف ثالث.
