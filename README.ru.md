## 🌟 Основные возможности

- 🛡️ Приватность в приоритете и поддержка DoH (DNS-over-HTTPS).
- ⚡ Лёгкая маршрутизация через локальный VPN: перехватываются только DNS-запросы (порт 53 UDP/TCP).
- 🚀 Преднастроенный список быстрых и надёжных резолверов: Cloudflare, Google, Quad9, Shecan и др.
- 🧩 Виджеты и Quick Tile для быстрого доступа.
- 🎨 Современный интерфейс (Glassmorphic), тёмная тема, индикаторы состояния DNS.
- 🔄 Автоподключение при загрузке (опционально).

## 🏗️ Архитектура и принцип работы

1. Приложение создаёт локальный виртуальный интерфейс TUN (`VpnService`) и перехватывает только DNS-адреса назначения.
2. При включённом DoH перехваченные DNS-запросы преобразуются в HTTPS-запросы в соответствии с RFC 8484 и отправляются по TLS к выбранному резолверу.
3. Приложение избегает постоянного логирования и не отправляет телеметрию третьим лицам.

## 🚀 Быстрый старт

1. Установите APK из раздела [Releases](https://github.com/SFDNSAPP/sfdns-pro/releases).
2. Откройте приложение и предоставьте разрешение VPN.
3. Выберите резолвер из списка или введите кастомные адреса DNS.
4. Включите DoH в настройках при желании.
5. Используйте Quick Tile или виджет для быстрого подключения.

---
## 🔒 Безопасность и конфиденциальность

- `allowBackup` отключён.
- Plaintext-трафик отключён (`usesCleartextTraffic="false"`).
- Запросы DNS не логируются и телеметрия не отправляется третьим лицам.
