## 🌟 الميزات الرئيسية

- 🛡️ **الخصوصية أولاً مع DoH**: دعم استعلامات DNS-over-HTTPS المشفرة لمنع التجسس وتزييف نظام أسماء النطاقات (DNS Spoofing) وحجب مزودي الخدمة.
- ⚡ **توجيه محلي خفيف وذكي**: اعتراض استعلامات منفذ 53 فقط (UDP/TCP). تمر كافة بيانات الإنترنت الأخرى مباشرة دون أي تأثير على السرعة.
- 🚀 **خوادم سريعة ومجهزة مسبقاً**:
  - **Cloudflare** (`1.1.1.1`)
  - **Google Public DNS** (`8.8.8.8`)
  - **Quad9** (`9.9.9.9`)
  - **Electro** (`78.157.42.100`)
  - **Radar Game** (`10.201.201.201`)
  - **Shecan** (`178.22.122.100`)
  - **403 Online** (`10.202.10.202`)
  - **Begzar** (`185.55.226.26`)
  - **إمكانية إدخال خوادم DNS مخصصة** (IPv4 و IPv6)
- 🧩 **عناصر واجهة المستخدم وقرميد الإعدادات السريعة (Tile)**: إمكانية تشغيل وإيقاف الاتصال بلمسة واحدة من شريط الإشعارات أو الشاشة الرئيسية.
- 🎨 **واجهة مستخدم عصرية بتصميم سايبربنك**: حركات سلسة ووضع ليلي متطور مع مؤشرات Ping بالوقت الفعلي.
- 🔄 **اتصال تلقائي عند تشغيل الهاتف**: بدء التشغيل في الخلفية اختياريًا بعد إعادة تشغيل الجهاز.
- 🎮 **رادار اختبار سرعة الألعاب**: قياس دقيق ومباشر لزمن الاستجابة عبر مقابس UDP/TCP لتجربة ألعاب سلسة.
- 🛡️ **النفق المقسم (Split Tunneling)**: استثناء التطبيقات المصرفية أو المحلية من توجيه DNS حسب الرغبة.

## 🏗️ بنية النظام وطريقة العمل

1. **حلقة خدمة VpnService المحلية**: ينشئ التطبيق واجهة TUN افتراضية محلية. بدلاً من توجيه كل حركة الإنترنت، يعترض حصرياً استعلامات منفذ DNS (منفذ 53).
2. **معالجة DoH**: عند تفعيل ميزة DoH، يتم تحويل الاستعلامات إلى طلبات HTTPS متوافقة مع معيار RFC 8484 وإرسالها مشفرة إلى الخادم المختار.
3. **انعدام السجلات وأعلى أداء**: لا يقوم التطبيق بتخزين أي سجلات تصفح ولا يرسل أي بيانات تحليلية لجهات خارجية.

## 🚀 دليل البدء السريع

1. قم بتنزيل وتثبيت ملف APK من [صفحة الإصدارات](https://github.com/SFDNSAPP/sfdns-pro/releases).
2. افتح التطبيق وامنح إذن اتصال VPN المحلي عند المطالبة.
3. اختر خادماً من القائمة الجاهزة أو أدخل عناوين IP المخصصة.
4. فعّل بروتوكول DoH من الإعدادات للتمتع بأقصى درجات التشفير.
5. اضغط على زر الاتصال الرئيسي أو استخدم قرميد الإعدادات السريعة.

## 🛠️ البناء والتثبيت من المصدر

### المتطلبات
- بيئة Android Studio الإصدار Ladybug أو أحدث
- حزمة تطوير جافا JDK 17 أو 21
- حزمة SDK 34 أو 36 (أندرويد 7.0 كحد أدنى - SDK 24)

### أوامر البناء بواسطة Gradle
```bash
# استنساخ المستودع
git clone https://github.com/SFDNSAPP/sfdns-pro.git
cd sfdns-pro

# تشغيل اختبارات الوحدة
gradle testDebugUnitTest

# بناء حزمة APK النهائية
gradle assembleRelease
```

- تم تعطيل النسخ الاحتياطي التلقائي (`allowBackup="false"`) لحماية بيانات التطبيق الحساسة.

## ❓ الأسئلة الشائعة (FAQ)

**س: هل يمر كل تصفحي للإنترنت عبر خوادم VPN؟**  
ج: لا. يقتصر عمل التطبيق على توجيه طلبات ترجمة النطاقات (DNS على المنفذ 53) فقط، في حين يمر باقي الاتصال بالإنترنت بشكل طبيعي ومباشر.

**س: هل يتم تسجيل استعلامات DNS الخاصة بي؟**  
ج: لا، التطبيق مصمم بأعلى معايير الخصوصية ولا يقوم بحفظ أو تسجيل أي نشاط.

**س: هل يحتاج التطبيق إلى صلاحيات الروت (Root)؟**  
ج: لا يحتاج التطبيق لأي صلاحيات روت، ويعمل على كافة أجهزة أندرويد بدءاً من الإصدار 7.0 وما فوق.
