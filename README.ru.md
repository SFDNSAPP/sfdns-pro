Продвинутое, легкое и ориентированное на конфиденциальность Android-приложение для смены DNS-серверов и безопасного туннелирования DNS-запросов через протокол **DNS-over-HTTPS (DoH)**. Написано на Kotlin с использованием стандартного локального сервиса `VpnService` для перехвата исключительно DNS-трафика без замедления скорости интернета и разряда батареи.

## 🌟 Ключевые возможности

- 🛡️ **Конфиденциальность и DoH**: Защита от DNS-спуфинга, перехвата трафика и подмены ответов провайдером благодаря шифрованию DNS-over-HTTPS.
- ⚡ **Легковесная локальная маршрутизация**: Перехватывает только запросы к порту 53 (UDP/TCP). Весь остальной трафик идет напрямую без потерь в скорости.
- 🚀 **Готовый список быстрых и антисанкционных серверов**:
  - **Cloudflare** (`1.1.1.1`)
  - **Google Public DNS** (`8.8.8.8`)
  - **Quad9** (`9.9.9.9`)
  - **Electro** (`78.157.42.100`)
  - **Radar Game** (`10.201.201.201`)
  - **Shecan** (`178.22.122.100`)
  - **403 Online** (`10.202.10.202`)
  - **Begzar** (`185.55.226.26`)
  - **Поддержка собственных DNS-серверов** (IPv4 и IPv6)
- 🧩 **Виджеты на рабочий стол и плитка быстрых настроек**: Включение и отключение в один клик через Quick Settings Tile или виджет.
- 🎨 **Современный Cyberpunk интерфейс**: Плавные анимации, темная тема, индикаторы пинга в реальном времени.
- 🔄 **Автозапуск при загрузке**: Опциональный запуск службы после перезагрузки устройства.
- 🎮 **Игровой радар (Ping Benchmark)**: Реальный замер задержки через UDP/TCP сокеты для онлайн-игр (PUBG, Warzone, Free Fire и др.).
- 🛡️ **Раздельное туннелирование (Split Tunneling)**: Возможность исключить банковские или локальные приложения из DNS-туннеля.

## 🏗️ Архитектура и принцип работы

1. **Локальный цикл VpnService**: Приложение создает виртуальный локальный TUN-интерфейс. Вместо проксирования всего интернет-трафика перехватываются только запросы к DNS-серверам.
2. **Обработка DoH**: При включенном DoH захваченные DNS-запросы преобразуются в HTTPS-запросы стандарта RFC 8484 и отправляются через TLS на выбранный резолвер.
3. **Отсутствие логов и максимальная производительность**: Приложение не ведет журналы запросов и не передает данные аналитики третьим сторонам.

## 🚀 Быстрый старт

1. Установите APK со [страницы релизов](https://github.com/SFDNSAPP/sfdns-pro/releases).
2. Запустите приложение и подтвердите запрос на создание VPN-подключения.
3. Выберите DNS-сервер из списка или введите свои адреса.
4. Включите DoH в настройках для повышенной защиты.
5. Нажмите кнопку подключения или используйте плитку в шторке уведомлений.

### Требования
- Android Studio Ladybug или новее
- JDK 17 или 21

gradle testDebugUnitTest

# Сборка Release APK
gradle assembleRelease

## ❓ Часто задаваемые вопросы (FAQ)

**В: Проходит ли весь мой интернет-трафик через VPN?**  
О: Нет. Приложение обрабатывает только DNS-запросы (порт 53). Все остальные соединения идут напрямую через вашего провайдера.

**В: Ведется ли журнал моих DNS-запросов?**  
О: Нет. Приложение не сохраняет историю запросов и не передает данные третьим лицам.

**В: Нужны ли Root-права?**  
О: Нет. Используется стандартный Android API `VpnService`, права суперпользователя не требуются.
