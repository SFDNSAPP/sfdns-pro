## 🌟 Основные возможности

- 🛡️ Приватность в приоритете и поддержка DoH (DNS-over-HTTPS) для защиты от подмены DNS и перехвата.
- ⚡ Лёгкая маршрутизация через локальный VPN: перехватываются только DNS-пакеты (порт 53 UDP/TCP); остальной трафик идёт напрямую.
- 🚀 Преднастроенный список быстрых и надёжных резолверов:
  - Cloudflare (`1.1.1.1`)
  - Google Public DNS (`8.8.8.8`)
  - Quad9 (`9.9.9.9`)
  - Shecan (`178.22.122.100`)
  - Electro (`78.157.42.100`)
  - Radar Game (`10.201.201.201`)
  - 403 Online (`10.202.10.202`)
  - Begzar (`185.55.226.26`)
  - Поддержка ввода кастомных Primary & Secondary DNS
- 🧩 Виджеты и Quick Tile для быстрого переключения соединения и выбора сервера.
- 🎨 Современный Glassmorphic UI, тёмная тема, индикаторы пинга и состояния DNS.
- 🔄 Автоподключение при загрузке (опционально).

## 🏗️ Архитектура и принцип работы

1. Приложение создаёт локальный виртуальный интерфейс TUN (`VpnService`) и перехватывает только DNS-назначения.
2. Когда включён DoH, перехваченные DNS-запросы преобразуются в HTTPS-запросы в соответствии с RFC 8484 и отправляются по TLS к выбранному резолверу (например, `https://1.1.1.1/dns-query`).
3. Приложение избегает постоянного логирования и не отправляет телеметрию третьим лицам.

## 🚀 Быстрый старт

1. Установите APK из раздела [Releases](https://github.com/SFDNSAPP/sfdns-pro/releases).
2. Откройте приложение и предоставьте разрешение VPN.
3. Выберите резолвер из списка или введите кастомные адреса DNS.
4. Включите DoH в настройках для шифрования DNS (рекомендуется).
5. Используйте Quick Tile или виджет для быстрого подключения/отключения.

## 🔒 Безопасность и конфиденциальность

- `allowBackup` отключён, чтобы избежать извлечения чувствительных данных приложения.
- Plaintext-трафик отключён (`usesCleartextTraffic="false"`).
- Приложение не собирает и не отправляет телеметрию третьим лицам по умолчанию.

## ❓ FAQ

Q: Будет ли всё моё трафик проходить через VPN?

A: Нет. Приложение перехватывает только DNS-запросы (порт 53) и отправляет их на выбранный резолвер; остальной трафик идёт напрямую.

Q: Логируются ли мои DNS-запросы?

A: Нет. Приложение минимизирует логирование и не отправляет телеметрию третьим лицам.

Q: Будет ли работать на рутованных устройствах или старых версиях Android?

A: Приложение использует VpnService и поддерживает API level 24+. Рут не требуется.

Q: Как я могу помочь с переводами или исправлениями?

A: Откройте Issue или отправьте Pull Request согласно инструкциям в разделе Contributing.
