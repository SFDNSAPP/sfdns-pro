# DNS Changer & DoH Proxy for Android

---
## 🌟 ویژگی‌های کلیدی

- 🛡️ حریم خصوصی اولویت دارد و DoH ایمن را پشتیبانی می‌کند (DNS-over-HTTPS).
- ⚡ مسیر‌یابی سبک وزن با VPN محلی: تنها ترافیک DNS (پورت 53 UDP/TCP) رهگیری می‌شود.
- 🚀 فهرست پیش‌فرض از resolverهای سریع و قابل اعتماد: Cloudflare، Google، Quad9، Shecan و غیره.
- 🧩 ویجت‌ها و Quick Tile برای دسترسی سریع.
- 🎨 رابط کاربری مدرن (Glassmorphic)، حالت تیره و شاخص‌های وضعیت DNS.
- 🔄 اتصال خودکار پس از بوت (اختیاری).

## 🏗️ معماری و نحوهٔ کار

1. اپ یک رابط مجازی TUN محلی (`VpnService`) ایجاد می‌کند و فقط مقصدهای DNS را رهگیری می‌کند.
2. زمانی که DoH فعال است، پرس‌وجوهای DNS گرفته‌شده به درخواست‌های HTTPS مطابق RFC 8484 تبدیل می‌شوند و از طریق TLS به resolver ارسال می‌شوند.
3. برنامه از لاگ‌گیری ماندگار خودداری کرده و telemetry به اشخاص ثالث ارسال نمی‌کند.

## 🚀 راه‌اندازی سریع

1. APK را از [Releases](https://github.com/SFDNSAPP/sfdns-pro/releases) نصب کنید.
2. برنامه را باز کنید و دسترسی VPN را بپذیرید.
3. یک resolver انتخاب کنید یا آدرس DNS سفارشی وارد کنید.
4. در صورت تمایل DoH را فعال کنید.
5. از Quick Tile یا ویجت برای اتصال سریع استفاده کنید.

## 🔒 امنیت و حریم خصوصی

- `allowBackup` غیرفعال است.
- ترافیک Cleartext غیرفعال است (`usesCleartextTraffic="false"`).
- اطلاعات کاربران لاگ یا telemetry ارسال نمی‌شود.
