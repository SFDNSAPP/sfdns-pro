## 🌟 الميزات الرئيسية

- 🛡️ الخصوصية أولاً ودعم DoH المشفر (DNS-over-HTTPS) للحماية من تزوير DNS والتجسس.
- ⚡ توجيه خفيف الوزن عبر VPN محلي: يتم اعتراض طلبات DNS فقط (المنفذ 53 UDP/TCP)، بينما تظل بقية حركة المرور غير متأثرة.
- 🚀 قائمة مبدئية من الخوادم السريعة والموثوقة:
  - Cloudflare (`1.1.1.1`)
  - Google Public DNS (`8.8.8.8`)
  - Quad9 (`9.9.9.9`)
  - Shecan (`178.22.122.100`)
  - Electro (`78.157.42.100`)
  - Radar Game (`10.201.201.201`)
  - 403 Online (`10.202.10.202`)
  - Begzar (`185.55.226.26`)
  - دعم إدخال DNS مخصص (Primary & Secondary)
- 🧩 عناصر واجهة وQuick Tile: تبديل الاتصال بسرعة من خلال Quick Settings أو الودجات.
- 🎨 واجهة زجاجية عصرية، وضع داكن ومؤشرات حالة DNS.
- 🔄 التشغيل التلقائي عند الإقلاع (اختياري).

## 🏗️ البنية وطريقة العمل

1. ينشئ التطبيق واجهة TUN افتراضية محلية (`VpnService`) ويعترض وجهات DNS فقط بدلاً من توجيه كل حركة المرور.
2. عند تمكين DoH، تُحوّل استعلامات DNS المعترضة إلى طلبات HTTPS متوافقة مع RFC 8484 وتُرسل عبر TLS إلى الخادم المختار (مثل `https://1.1.1.1/dns-query`).
3. لا يتم الاحتفاظ بسجلات دائمة ويُحاول التطبيق تقليل بصمته وعدم إرسال telemetry لأطراف ثالثة.

## 🚀 بدء سريع

1. ثبّت APK من صفحة [Releases](https://github.com/SFDNSAPP/sfdns-pro/releases).
2. افتح التطبيق وامنحه إذن VPN.
3. اختر محلل (resolver) أو أدخل عناوين DNS مخصصة.
4. فعّل DoH في الإعدادات للحصول على DNS مشفر (مستحسن).
5. استخدم Quick Tile أو الودجات للتوصيل/الانفصال بسرعة.

---
## 🔒 الأمان والخصوصية

- `allowBackup` معطّل لمنع استخراج حالة التطبيق الحساسة.
- حركة مرور النصّ الواضح (Cleartext) معطّلة (`usesCleartextTraffic="false"`).
- لا يتم جمع بيانات المستخدم أو إرسال telemetry إلى أطراف ثالثة بشكل افتراضي.

## ❓ الأسئلة المتكررة

س: هل يقوم التطبيق بتوجيه كل حركة المرور عبر VPN؟

ج: لا. التطبيق يعترض استعلامات DNS فقط (المنفذ 53) ويرسلها إلى المحلل المحدد؛ تبقى بقية الحركة كما هي.

س: هل تُسجل استعلامات DNS أو تُرسل إلى طرف ثالث؟

ج: لا. التطبيق لا يسجل استعلامات DNS بشكل دائم ولا يرسل telemetry إلى أطراف ثالثة.

س: هل يعمل على الأجهزة ذات صلاحية الروت أو على إصدارات أقدم من أندرويد؟

ج: التطبيق يعمل عبر `VpnService` ويتطلب API level 24+؛ لا حاجة للروت.

س: كيف أساهم بالترجمات أو التعديلات؟

ج: افتح Issue أو قدّم Pull Request باتباع إرشادات المساهمة.
